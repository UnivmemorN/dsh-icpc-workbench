# 合并题库与跨站通过状态

> **开发参考** · [开发文档索引](development/README.md) · 日常操作请看[用户手册](user/README.md)。本文保留既有地址，供实现与排错核对。


在「题库」选择 **合并题库（跨站去重）**，即可一起浏览已导入的各平台题目。选择参与统计的各站账号后，列表会汇总这些账号的真实 AC；每个平台最多选择一个账号。其他已保存账号的成绩不会自动参与。

## 账号标识怎么填

在「账号与同步」展开「添加账号」后可填写标识，也可直接粘贴公开个人主页链接：

- **Codeforces Handle** 是账号用户名。例如个人主页 `https://codeforces.com/profile/tourist` 中的 `tourist`。请填写自己的用户名。
- **洛谷 UID** 是数字用户编号。打开自己的洛谷个人主页，复制网址 `/user/` 后面的数字，例如 `https://www.luogu.com.cn/user/123456` 中的 `123456`。它与可修改的昵称不同。

以上仅用于解释格式。添加账号只保存公开标识；获取做题记录需在「账号与同步」页面导入或同步。洛谷支持在该页展开「连接洛谷 / 更新登录凭据」，用本机保存的登录凭据同步提交记录；不连接时 JSON/CSV 手工导入仍然可用。详见 [洛谷账号连接与同步](luogu-sync.md)。

## 哪些题会合并

当前自动识别官方 Codeforces 主站题号与洛谷对应的 CF 镜像编号，例如 **CF 1A ↔ 洛谷 CF1A**。同一组在总数和分页中计为一道题，保留每个站点的题号、名称、原题链接和难度。两站难度独立展示；难度排序先选择具体平台。

映射由明确的原题编号决定。不同题号的同名题、E1/E2 等不同版本、Gym 题及尚无明确映射的题目仍分别显示。当前没有任意两题的手工合并或基于相似标题的自动推断。官方示例：[洛谷 CF1A](https://www.luogu.com.cn/problem/CF1A)。

这条等价规则是**唯一的**判定依据，由纯函数 `cfMirrorIdentity()` 实现（`src/domain/problem-equivalence.ts`）。合并题库与「等价题题解复用」（[Stage 33B](reports/stage-33b-cf-mirror-editorial.md)）共用它，因此两处不可能对同一对题得出不同结论。只有**两边都不带 `domain`、实例都是官方实例、编号都规范**时才成立：比赛号为正整数且小于 100000（无前导零），题号为大写字母加可选数字后缀且**原样保留**（`A0` 与 `A01` 是不同题号）。以下一律**不**合并：Gym/训练场题目；带 `domain` 的记录；非官方实例或镜像站；`cf1a`、`1a`、`CF01A` 这类大小写或补零写法；纯数字题号。**绝不**按标题、原始标签、评分或题面相似度推断同题，也不会让模型判断两题是否相同。

**注意区别：** 合并题库只按上面的**标识符**规则分组。Codeforces 同一场 Div.1 / Div.2 里可能出现同一道题（[Stage 33B 修订版](reports/stage-33b-cf-editorial-alias.md)），但那是**另一条**规则（`cf-editorial-alias-v1`），而且**只用于定位官方题解的章节**：它**不会**把两个 Codeforces 条目合并成一道题，也不会联动 AC 或复制标签。两条规则各自独立验证、各自记录。

## 通过状态从哪里来

一组题在所选任一账号上有真实 AC，合并视图就显示「已通过」，并注明账号、平台、题号和提交时间。重复 AC 只产生一个通过状态，后来的 WA 不会撤销已有 AC。即使 AC 所在站点的题目信息尚未导入，只要原始提交记录存在且编号可明确关联，也可提供通过依据。

「本平台已通过」与「关联题目已通过」分别表示原站 AC 与跨站关联结果。联动是本地浏览视图，不会写入另一平台的提交记录、替用户提交代码，或修改原始成绩。打开某个站点的题目详情时，提示与复盘使用该站点所选账号；不会套用其他平台账号。

原始标签、题解、分析快照和人工决定仍归属于各站题目。关联 AC 不会自动采用另一站的标签，也不会自动公开未通过站点的题解。正式薄弱项与训练计划沿用各账号自身的原始记录。

## 浏览和筛选

支持搜索任一成员题号或标题、筛选已通过/未确认通过、仅看尝试过的题、题号及名称排序，以及首页/末页/页码跳转。计数是当前筛选下的合并组数。筛选某个平台时，显示包含该平台题目的组，仍保留所选其他平台账号提供的同题 AC 依据。

导入和同步需要明确的数据来源，可通过「导入 / 同步各平台数据」返回分平台题库。合并浏览本身不下载数据，也不调用模型。
