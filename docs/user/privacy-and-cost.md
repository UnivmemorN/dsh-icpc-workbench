# 隐私与费用

本页说明哪些操作会调用模型、模型凭据归谁管、审计会记录什么、本地数据在哪里，以及费用与余额显示的口径。

## 哪些操作调用模型

| 不调用模型 | 调用模型（都必须由你显式触发） |
| --- | --- |
| 查看题面、公式与折叠块、复制代码、查看原文 | 标签分析批次：「确认开始付费分析」「确认继续付费分析」 |
| 题库搜索、筛选、排序、分页、切换分平台/合并题库 | 逐级提示 / 完整讲解请求 |
| 知识点、薄弱项、能力面板的查看、筛选与翻页 | 训练计划：「生成 AI 计划（调用模型）」 |
| 平台同步（CF 目录/提交、洛谷同步、CF 评分同步） | 能力评估：「生成 AI 评估报告」 |
| JSON/CSV 预览与导入、手工补充题目资料 | （无题解推理是该批次中的一个独立计数角色，只在批次运行时发生） |
| 免费准备：批次准备、计划准备、评估准备、规则计划预览 | |
| 修改完成方式、跳过/回收站/恢复、备份数据库 | |
| 洛谷昵称读取、检查登录 | |

两个关键保证：

- **「免费准备」永远不产生费用**，也不占用 24 小时付费额度；它只读取本地数据并冻结一份准备记录。
- 页面挂载、切换视图、读取历史、轮询状态都不会派发付费调用；唯一触发点是上面那几个明确写有“调用模型 / 付费”的按钮。

## 模型与凭据归属

- 每次辅助模型调用都通过 dsh 公开的 LLM 服务发起；插件**不直连提供方、不内置提供方 SDK、也不从自己的配置或设置里读取 API key**。
- 插件配置与设置只包含提供方名、模型名、额度、限制与数据目录；**没有** API key、token 或授权头字段。
- 提供方凭据的存储、轮换与宿主日志由 dsh 负责，超出本插件的可见范围。
- 模型策略统一为 DeepSeek V4.1 Flash + max；旧配置升级时会统一模型并保留额度与超时，新设置不接受 Pro 或其他模型。

## 审计会话会记录什么

dsh 会在本地审计会话中保留实际发送给模型的输入、模型输出和调用用量。因此，保存到本地的题面或外部解析在你显式用于 AI 分析后，其发送内容也会成为审计材料。

不要在这些材料中粘贴 API key、Cookie 或密码。插件不会识别任意形式的秘密；错误通道会隐藏上游敏感诊断，但不会替你清理主动粘贴的正文。旧审计记录不会自动清除。

洛谷登录 Cookie 通过专用表单交给本机连接功能，存入 Windows 凭据管理器，仅用于访问洛谷；它与模型凭据独立，不进入模型请求或审计材料。

## 本地数据在哪里

- **训练数据目录**：默认在系统应用数据目录下的 `dsh-icpc-workbench`，可以在安装时用 `dataDir` 改成独立绝对路径；具体路径显示在「设置 → 本地数据」。题库、提交记录、快照、复盘、统计、计划与报告都在这里。
- **数据库升级**前会自动生成可验证备份；界面上的「创建本地备份」只写插件自己的 `backups` 目录并返回本地路径。
- **卸载插件保留训练数据**；旧版本插件会拒绝打开更新版本的数据库。
- **洛谷凭据**在 Windows 凭据管理器中；「断开连接」只删除凭据，已同步数据保留。
- **模型审计会话**由 dsh 保存，训练数据由插件保存，两者分开。
- 仓库与发布包中不包含凭据、会话、用户数据、下载的题面/题解正文、工件或日志。

## 费用怎么算

- 免费准备：0 费用、0 额度占用。
- 生成一份 AI 计划或评估报告各调用一次模型；标签批次可能包含多次分析、复核与重试。费用取决于输入与输出用量，界面不会给出“费用预测”，只给出调用**上限**。
- 批次重试计入额度；请求被判定为无效输出时保留实际用量但不保存结果；取消已派发的调用仍保留其费用。
- 提供方从未报告用量时记为**未知费用**：仍然占用额度，不会显示成 0，也不会自动重试（免费重试可能掩盖一次已经计费的调用）。
- 计划与逐级提示各自有独立的 24 小时计数器，只共用同一个上限值（默认 10）；能力评估有独立计数器，取同一上限值；计划与评估各自最多同时运行一个调用。

## 余额显示（可选的独立插件）

DeepSeek 余额与会话花费估算由 [LemCAE 的 @lemcae/dsh-balance](https://github.com/LemCAE/dsh-balance)（MIT）提供，它不属于本插件包，也不会随本插件一起安装：

- 需要按 profile 单独安装到**实际运行工作台的那个 dsh profile**，重启 Web 界面后在左下角「设置 → DeepSeek 余额」查看详细卡片。
- 该卡片需要一个当前会话：先打开一个对话，再打开设置；没有会话时显示固定的“请先打开会话”提示。
- 它通过宿主已有的业务命令读取数据，不发模型请求、不创建会话、不保存凭据；余额来自官方余额 API，**会话花费只是按记录 token 与价格表估算，不是账单**。
- 在测试宿主上它可能需要做版本兼容处理；当前宿主的安装与兼容限制见[余额插件技术说明](https://github.com/UnivmemorN/dsh-icpc-workbench/blob/main/docs/dsh-balance-setup.md)。
- 该插件与本项目分别维护、分别卸载；ICPC 工作台的模型网关不会因此获得任何提供方凭据。
