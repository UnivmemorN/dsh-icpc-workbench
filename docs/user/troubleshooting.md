# 故障排查

本页按“你看到什么 → 可能原因 → 怎么做”组织。重试会请求平台资料，手工补充和跳过/回收站只修改本地记录；这些操作不会修改平台上的题目或提交，也不调用 AI。

## 症状与操作对照

| 症状 | 可能原因 | 怎么做 |
| --- | --- | --- |
| 题库某题没有题面 | 平台资料还没补齐；或这道题在洛谷属于个人题目、题面未公开 | 到题目详情「刷新平台材料」；仍缺失时在洛谷同步面板展开「待补题目与手动处理」点「重试此题」，或用「手工补充」写入你确认的标题与题面（不使用 AI、不调用模型）。不要填写虚构题面 |
| 洛谷题目编号是 `U…` / `T…` 且题面为空 | 自建/私有题目可能不公开题面（但 U/T 编号**不意味着**一定私有） | 先在浏览器打开原题确认是否公开；能访问就稍后重试；确实不提供就手工补充，或跳过/移入回收站 |
| 同步失败，提示与“登录”有关，失败环节是**读取提交记录** | 这次认证读取被平台要求重新登录 | 先在普通浏览器确认账号能登录并通过验证，点「检查登录」核对当前登录，再手动继续同步；若检查也失败，重新复制 `__client_id` Value 并「更新登录凭据」 |
| 同步失败，失败环节是**补齐题目资料** | 公开题目数据这一次没取到：读取题面被要求登录、题目本身受限（403）、限流或页面异常 | 已同步的提交记录、历史覆盖与检查点都会保留，待补题目继续排队。先看固定错误码：`auth_required` 表示需要有效登录，旧记录不能证明已经用登录态重试过；先点「重试此题」，当前版本会在匿名读取被要求登录时使用当前账号保存的会话重试，仍失败时点「检查登录」并按结果更新凭据。`forbidden` 表示访问被拒绝，可打开原题核对当前账号权限、稍后重试或手工补充；限流或页面异常可稍后点「开始 / 继续同步」补资料，或用「补齐全部积压资料（不使用 AI）」一次处理当前积压 |
| 同步失败，错误码类似 `changed_response` | 平台返回结构或同步游标与预期不符，可能只是人工验证或网站改版，不一定是本地进度损坏 | 先在普通浏览器确认账号能登录并通过验证；确认插件与当前平台响应、宿主版本的兼容情况后重试，本地检查点会保留。不要为了重试清空进度，也不要把自动重试当修复。只有确认平台与本地长期不一致、且确实想重新核对全部历史时才做「全历史完整核对」 |
| 网页题面完整，但旧版本反复提示“返回内容与预期不符” | 0.1.23 及以前可能把平台返回的零值内存限制误判成题目损坏 | 升级到 0.1.24 后，在「待补题目与手动处理」点「重试此题」。若属于这个已修复问题，无需更新 Cookie 或手工补写题面；仍失败时按实际原因处理 |
| 「检查登录」成功，但同步仍然失败 | 这是两件独立的事实：探针只说明“现在能登录” | 查看「同步详情」里的失败环节与固定错误码，按上面的对应行处理；检查登录不会撤销已记录的失败 |
| Cookie 过期或被要求重新登录 | 平台会话失效 | 在浏览器重新登录洛谷，按 F12 重新复制 `__client_id` 的 **Value**，在「更新登录凭据」里重新连接；`_uid` 必须与当前账号一致 |
| 「断开连接」报 `cleanup_failed` | 旧凭据没有从 Windows 凭据管理器删除 | 再点一次「断开连接」；必要时重启 dsh 后重试 |
| 合并题库里看不到某道跨站同题 | 当前只自动识别官方 CF 主站题号与洛谷 CF 镜像编号 | 不同题号的同名题、E1/E2、Gym 题与无明确映射的题仍分别显示；没有手工合并功能。需要按站浏览时切回分平台题库 |
| 合并题库里不能批量修改完成方式 | 合并视图只做跨站浏览与通过联动 | 切到「分平台题库」，选择该平台账号后再批量编辑 |
| 余额面板看不到余额，或提示没有会话 | 余额是可选的独立插件，需要安装到实际运行工作台的 profile；会话花费需要一个当前会话 | 打开一个对话后再从「设置 → DeepSeek 余额」查看；确认该插件装在正在使用的 profile 中，并按其安装说明处理宿主版本兼容 |
| 改了完成方式，旧报告没变化 | AI 报告是生成时的快照 | 这是预期行为：本地统计与规则评估会用最新记录，AI 报告需要重新「免费准备」并显式生成 |
| 「生成 AI 计划 / 评估」被拒绝，提示设置已变化或准备过期 | 准备冻结了设置版本与数据快照，之后发生了变化 | 重新「免费准备」（免费、不扣费）再生成；不要在旧准备上继续 |
| 提示 24 小时额度已用完 | 计划/提示或评估的滚动 24 小时计数达到上限 | 等到窗口滚动后再试；付费失败与未知费用仍会保留在记录里 |
| 分析批次里部分题目没有运行 | 这些题缺少材料快照，准备时被报告为材料缺失 | 到题目详情刷新平台材料或用[手工导入](manual-import.md)/粘贴外部答案补材料，再重新准备；材料缺失不会建立任务也不会调用模型 |
| 启动时被拒绝，提示数据目录无效 | `dataDir` 不是绝对路径，或位于 dsh 安装目录 / dsh home 内 | 改成独立的绝对路径后重新启动；见[安装与首次启动](installation.md) |
| 旧版插件无法打开数据库 | 数据库版本比插件支持的更新 | 换回较新版本的插件；升级前插件会自动生成可验证备份，旧版本插件拒绝打开新库 |
| 报告里出现“未知费用” | 提供方没有报告用量 | 这不是 0 费用：记录会保留“未知”，也不会自动免费重试。可在下次调用前检查设置与额度 |
| 界面显示“尚未读取到同步状态 / 上一项操作仍在进行” | 有操作正在运行，或另一个 dsh 实例持有租约 | 等当前操作结束或点「暂停本轮」，再逐题重试/手工补充；不要同时开两个实例同步同一账号 |

## 恢复、跳过与回收站：完整流程与影响

出题测试题、私有题或平台已删除的题目可以不出现在你的训练统计里，而且**不会**被物理删除。

1. 进入「账号与同步」，选择洛谷账号。
2. 展开「待补题目与手动处理 · 已跳过 / 回收站」，选择页签：**待补题目**、**已跳过**、**回收站**。
3. 单题操作，或勾选本页后批量操作（每次最多 50 题，跨页不保留选择）。确认区域会列出具体题号与影响范围；如果状态在你选择后发生了变化，整批会被拒绝，刷新后重新选择。
4. 恢复时如果题面仍然缺失，题目会回到当前账号的待补队列；队列满时保持原状态并显示原因，不会部分恢复。

| 选择 | 立即影响 | 后续影响 | 可逆性 |
| --- | --- | --- | --- |
| 重试此题 | 只请求这一题的公开资料 | 成功则离开待补列表；暂不提供或失败则留在列表 | 可反复重试 |
| 手工补充 | 用你提供的标题与题面写入本地并生成新快照 | 只补资料：不改通过记录、不采用标签、不抓平台数据、不使用 AI | 原始记录与快照保留；需要改动时使用题目材料入口 |
| 跳过 | 从该来源各账号的补题面队列移除 | 保留题目、做题记录与统计；继续导入历史，但不再补齐该题资料 | 在「已跳过」恢复 |
| 移入回收站 | 从补题面队列移除，隐藏题目 | 排除对应提交与复盘的统计、新能力评估输入与新训练选题；原始记录可更新但不会重新显示或排队 | 在「回收站」恢复 |
| 恢复 | 题面仍缺失时回到待补队列 | 恢复使用保留的原始记录 | 无物理清空操作 |

补充说明：

- 同一个洛谷站点上，该题的处理状态由所有本地账号共用；CF 等其他来源的同题记录独立保留。合并题库不再用被移入回收站的洛谷记录提供 AC 证据。
- 操作只写本地数据库：不改动平台、不调用 AI、不需要 Cookie。同步正在运行时要先暂停；其他实例持有租约时会拒绝。
- 旧的 AI 评估报告与已生成计划保留为历史快照，需要重新生成才能反映当前数据；账号级官方比赛评分与手工虚拟表现分不受回收站影响。

按需要选择：想保留统计但停止补题面，使用「跳过」；希望从统计和新评估中排除，使用「移入回收站」。无需先填写题面，也无需逐个尝试所有操作。

## 向他人求助时

请提供这些信息，它们足以定位大多数问题：

- 插件版本、宿主版本与数据库版本：「设置 → 本地数据」；
- 固定错误码与**失败环节**（读取提交记录 / 补齐题目资料）、界面上的固定文案；
- 你执行的操作路径（例如「账号与同步 → 待补题目与手动处理 → 重试此题」）；
- 是否使用隔离 profile、`dataDir` 是否自定义（**不要**粘贴完整本地路径中的个人信息，只需说明是否自定义）。

请隐去 Cookie、`__client_id`、会话令牌、API key、账号密码，以及不希望公开的个人资料；也不要直接上传整个数据库或运行日志。
