# 标签与题解材料

本页讲四件事：平台原始标签与“已采用标签”的区别、标签分析批次怎么跑、第二次独立复核与人工审核怎样工作、以及你粘贴的外部答案会被怎么使用。

## 四类信息始终分开

题目详情和统计里同时存在四种不同的东西，它们**不能互相替代**：

| 类别 | 是什么 | 谁产生 |
| --- | --- | --- |
| 平台原始标签 | 平台自己的说法，可能宽泛、不完整或与训练方向不一致 | 平台（导入/同步得到） |
| AI 建议 | 模型读完题解材料后给出的候选标签，每条必须引用实际题解片段 | 标签分析 |
| 人工决定 | 你对每条建议的接受或拒绝，以及手工指定标签 | 你 |
| 当前采用的标签 | 正式参与薄弱项与知识点统计的有效标签 | 有效的模型复核结果或人工决定 |

平台原始标签永远不会自动变成正式标签，也不会被删除；原始标签可能不完整，参考统计不会自动变成“已采纳”。

## 在哪里操作

- **题目详情**（题库 → 打开一道题）：题面、「标签与来源」（平台原始标签、查看原始标签编号、当前采用的标签）、「查看当前分析与证据」、「手工指定标签」、「粘贴外部答案 / 用户提供解析」。
- **标签审核**：选择题目、免费准备批次、运行付费分析、浏览待人工审核题目、查看已保存批次。
- **薄弱项 / 知识点掌握情况**：按当前采用的标签与复盘记录统计。

## 已经有平台标签，还需要分析吗？

需要时仍然可以分析。**已有平台标签不会阻止完整性分析**：所有缺少当前快照、词表及审核版本完整性记录的题目都可以被准备；缺材料的题目会在准备结果里单独列出，并给出到题目详情补充材料的入口。

一次“已检查”的含义是：

> 一次成功的题解分析，之后跟着一次**独立的复核**，并且这次复核回答了“有没有遗漏”的问题（针对同一份冻结快照与同一个词表版本）。

因此：

- **已检查 ≠ 数学上穷尽**，只表示这套两遍流程在当前审核版本上确实运行过。
- 旧结果（本流程之前产生的）、仅无题解推理的结果、失败或取消的运行都**没有**检查记录，界面显示为“无完整性检查记录 — 未检查”，不会显示成“检查通过”。
- 空的分析结果也会触发复核，并占用该批次的分析额度。

## 第二次独立复核

复核不是重复一遍第一次的结论，而是：

- 独立读题解材料本身；
- 逐条判断第一次给出的每条建议；
- 再通读材料，查找第一次遗漏的方法（不依赖平台原始标签）；
- 必须回答“遗漏列表”（可以为空）。

复核发现的遗漏会作为**建议**进入人工审核队列。它们不会被产生它们的那次调用自动确认：人工接受或拒绝始终优先。如果一条“遗漏建议”重复了第一次已提出的标签、指向不存在的知识点、引用了外部解法或自我重复，整次调用会被判失败，不会部分采纳。

## 运行标签分析批次

1. 在「题库」勾选题目（或先在「标签审核 → 浏览待人工审核题目」里筛选）。
2. 在「标签审核 → 标签分析批次」设置**本批最多题数**（1–100）。
3. 按需勾选「重新分析（保留旧结果）」。默认只补查尚未完成当前版本完整性检查的题目；勾选后每题都会建立**独立的新任务**，旧任务、旧结果与旧标签历史全部保留。
4. 点「免费准备批次」——这一步**只建立任务，不调用模型**。准备结果会显示：
   - 将要使用的模型（分析、复核、无题解推理，均为 `max`）；
   - 题解材料的可用情况：已找到、已确认无题解、材料不全或获取失败；
   - 本批的调用上限（分析/复核次数、推理次数，含重试）——这是上限，不是费用预测；
   - 新任务、已跳过（现有完整性检查仍有效）、重跑（旧结果保留）、材料缺失四类题目的数量。
5. 核对后再点「确认开始付费分析」。运行中可以「暂停」「确认继续付费分析」「取消批次」「恢复中断状态」「刷新状态」。

关于「已跳过」：它只表示这些题目的当前快照已完成当前版本的完整性检查，**不代表所有标签都已正确**；旧版结果或缺少检查记录的任务不会被当作已完成。

关于材料缺失：没有材料快照的题目会被列为材料缺失，**不会建立任务也不会调用模型**；其余题目正常准备。请先到题目详情「刷新平台材料」或用[手工导入](manual-import.md)/粘贴外部答案补上材料，再重新准备。

批次状态会在界面上显示为：待开始、运行中、已暂停、已完成、已取消、失败、待人工审核、已分析、额度已用完。

## 人工审核

在「查看当前分析与证据」里，每条 AI 建议都带有：

- 目标知识点；
- 判断理由；
- **证据片段**（注明来自哪份题解）；
- 复核结论（或“尚无复核记录”）。

每条建议提供「人工接受」与「人工拒绝」，可以填写审核备注。「手工指定标签」区域可以对任意知识点执行「采用此标签」或「排除此标签」。无题解推理产生的草稿只供人工审核，不会被当成已确认结论。

重跑后的变化也是可见的：

- 若新的检查不再支持旧的自动采用，该标签会记录为待人工审核（过期分析），并**停止计数**；
- 人工接受/拒绝的决定**永远不会被覆盖**；
- 平台原始标签**永远不会被删除**。

## 没有题解时怎么办

只有**明确确认平台没有题解**且存在完整题面时，才允许进入 DSV4.1 Flash 推理；鉴权、限流和网络错误**不会**触发这条路径（它们不是“没有题解”的证据）。推理草稿同样需要人工审核。

如果平台不提供题解、但你有材料（老师讲解、你自己整理的解析、其他来源的说明），更好的做法是直接粘贴外部答案，让分析与复核基于真实材料进行。

## 粘贴外部答案 / 用户提供解析

入口：题目详情 →「粘贴外部答案 / 用户提供解析」。

- **来源标注**必填（例如 GPT6、教师解析、自己整理），最长 200 字符；**正文**最长 200000 字符，支持纯文本、Markdown 与代码，按原样保存并以安全文本显示；**出处链接**可选。
- 点「保存为本地用户提供解析」后：**只写本地，不调用模型、不产生费用，也不会自动采用任何标签**。界面会明确提示“本插件未核验其正确性”。
- 之后当你**显式**启动分析、独立复核或请求提示时，模型才会读取这份材料及来源说明，并仍按题解证据规则处理；独立复核也会检查遗漏。
- AI 训练计划只接收做题聚合与候选题元数据，**不接收**完整解析正文。
- 保存后可以点「选中此题并前往标签审核」，免费准备本题的分析，再显式启动付费调用。
- 相同标注、正文与链接的重复粘贴会复用已有快照；不同内容会产生新快照并保留旧材料与分析。切换题目会清除表单草稿（草稿不会在账号之间串用）；保存期间输入暂时锁定。如果保存时题目材料已经变化，会提示先刷新，你的输入不会被清空。
- 你标注的模型或作者名称**不代表**插件已认证来源，也不证明答案正确。

平台题解、用户提供解析、原始标签和人工决定分别保存，互不覆盖。

## 哪些操作调用模型

- 不调用：查看题面与标签、展开证据、浏览待审核题目、切换筛选、免费准备批次、查看历史批次状态。
- 调用（都需要你显式触发）：确认开始付费分析、逐级提示/完整讲解、生成 AI 计划、生成 AI 评估报告。

统一模型、额度与凭据边界见[隐私与费用](privacy-and-cost.md)；完整性检查的实现契约见[技术参考](https://github.com/UnivmemorN/dsh-icpc-workbench/blob/main/docs/completeness-review.md)。
