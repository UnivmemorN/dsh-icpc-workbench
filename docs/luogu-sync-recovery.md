# 题目资料补齐与手动处理

本页说明洛谷同步里「待补题目与手动处理」这一项：什么时候会出现、每一项显示什么、如何逐题重试，
以及平台不提供题面时如何只用本地内容手工补充。它只涉及**题目资料**（标题与题面）的本地记录，
不涉及提交记录、标签或自动确认。

## 什么时候会用到

同步读取提交记录时，会顺手为题目保存公开资料。如果某道题的公开资料这次没有取到，
这个题目键会留在**待补列表**里，同步不会丢掉它，之后可以继续补：

- 普通「开始 / 继续同步」每轮最多补 100 条题目资料，剩下的留给下一轮；
- 积压较多时可以点「补齐全部积压资料（不使用 AI）」，一次处理点击时已经存在的积压；
- 只想处理某一题、或者平台明确不提供这道题的题面时，展开「待补题目与手动处理（N）」逐题处理。

在卡片上，失败或积压的短句会直接指向这个展开项；展开项默认收起，**只有展开时才会读取待补列表**，
一次只读取一页（默认每页 20 题，可切到 25 题），不会把整个积压拉下来，也不会一次渲染很多输入框。

## 每一项显示什么

| 内容 | 含义 |
| --- | --- |
| 题目编号（链接） | 这道题在洛谷的原题链接，点开就是平台上的原页面，可以自己确认题面是否公开、是否还在。 |
| 标题 | 本地已经保存的标题；还没有保存过标题时会显示「本地还没有标题」，此时手工补充需要自己填标题。 |
| 逐题原因 | 这道题**最近一次**失败的原因、时间和累计失败次数。 |
| 尚无逐题失败记录 | 这条待补记录里没有逐题诊断。旧数据（写入时还没有逐题记录）会是这样，也可能只是还没尝试过；界面不会替你断言是哪一种。 |
| 当前待补 N 题 | 现在还没补齐资料的**题目键**数量。 |
| 历史失败尝试 M 次 | 这个账号累计的失败**尝试次数**。它是次数，不是 M 道失败题目：同一道题重试多次会累加。 |

已知逐题原因的题目会排在前面（由服务端排序，界面不再重排）；一页里有多少条已知原因会单独说明。
界面只显示固定分类的原因与固定句子，不显示原始异常、响应内容或样本，也不会根据错误码猜测
「Cookie 一定过期了」之类的结论——补资料这一步是匿名读取公开题目数据。

## 逐题重试

每一行的「重试此题」只重试**这一道题**，调用一次 `luogu.retryMetadata`。结果有三种，界面如实说明：

- **已补齐**：这一题离开待补列表，题库会刷新；
- **暂不提供**：平台对这道题（例如自建/私有题目）不提供公开资料，本题仍在待补列表，可以稍后重试或手工补充；
- **失败**：这次请求失败，原因按固定分类显示，题目仍在待补列表。

不会自动连续重试，不会开始整轮同步，不会调用 AI 模型，也不会改动历史覆盖、检查点、自动同步设置或计划。
本轮同步正在运行、另一个 dsh 实例持有租约、插件正在关闭，或者你已经有一个操作在进行时，
这些按钮会被禁用并给出原因，避免与正在运行的任务互相覆盖。

## 手工补充

平台不提供题面时，可以用行内的「手工补充」把**你自己知道的**内容写进本地记录。
同一时间只会打开一个表单；关闭表单、切换题目或切换账号都会卸载并清空草稿，草稿不会写进
`localStorage`，也不会在账号之间串用。

表单要求：

- 标题：只有本地还没有标题时才需要填写；已有标题时只显示为只读，不会被覆盖；
- 题面：真实的题目描述（Markdown），不能为空——这里不是填写「无法获取」之类备注的地方；
- 明确点「保存到本地」才会提交，提交时带上你刚才看到的快照编号（`expectedSnapshotId`）。

表单里会明确写着：

> 仅补齐本地题目资料，不改变通过记录或自动确认标签。
>
> 不使用 AI。

提交成功表示**用户提供的标题/题面**写入了本地题目行并生成了一个新的不可变快照，这一题离开待补列表。
它**不代表**从平台抓取成功：这个操作不发出任何平台请求、不保存平台标签或难度、也不声明任何题解来源。

如果提交时快照已经变化（例如另一处刚补过这道题），提交会被拒绝，界面会保留你的草稿，并提示你
先刷新待补列表、查看最新状态后再重新提交；界面**不会**用你的草稿覆盖最新快照，也不会自动改用旧快照编号重试。

## 题面为空时还能做什么

题面为空最常见的原因是这道题在洛谷上属于**个人题目**，题面没有公开（或只有作者自己可见）；
洛谷官方帮助手册的题目说明（<https://help.luogu.com.cn/manual/luogu/problem/>）是这一点的原始说明来源。
遇到这种题目可以：

1. 点题目编号打开原题，确认在浏览器里能否看到题面；
2. 能正常访问的话，稍后再点一次「重试此题」；
3. 平台确实不提供时，用「手工补充」填入自己确认过的标题与题面，仅作为**本地**训练资料使用。

请不要在这一步粘贴 Cookie、会话或任何登录材料：这个表单只接受题目资料文本，
补资料也不需要重新连接账号。
