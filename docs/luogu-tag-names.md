# 洛谷平台标签名称快照

本页说明本插件如何把洛谷的**数字标签编号**显示成可读的平台名称，以及这一显示层的来源、边界和维护方式。
它只影响显示：不改变任何已保存记录、统计口径、标签对照规则或复核结果。

## 为什么需要它

洛谷题目把平台标签以数字编号返回，适配器按 `luogu-tag:<id>` 原样保存；只有编号无法直接阅读。
本插件随版本附带一份公开的 **编号 → 平台名称** 快照，因此旧记录不需要重新导入、重新同步或改写数据库，
离线也能显示当时保存的编号对应的平台名称。名称只是洛谷原始标签的显示文本，不是本插件给出的分类或复核结论。

## 来源与范围

- 来源：[洛谷官方公开标签数据](https://www.luogu.com.cn/_lfe/tags)，核对日期 **2026-09-14**，共 **505** 条
  `(编号, 名称)` 对（每条编号唯一，名称按平台原文保留，包括个别名称中的不可见字符）。
- 只保留公开的标签编号与显示名；快照中不含题目、题解、提交、账号、成绩或任何用户材料，也不复制第三方代码。
- 快照随插件版本发布，独立于用户的提交记录；已有记录保持原样，**不需要迁移或重新导入**。
- 本插件不为这份公开元数据主张任何第三方许可证；洛谷未审核、未背书本插件。

## 显示规则

- **只在官方洛谷站点解析。** 仅当记录自己的来源实例是 `luogu.com.cn` 或 `www.luogu.com.cn` 时才会查名称；
  镜像部署、Codeforces、手工来源，以及来源信息缺失或无法在启动目录中解析的记录，一律原样显示保存的字符串。
- **只识别严格编号。** 只有 `^luogu-tag:-?\d+$` 会被当作编号；大小写不同、带空格、小数、正号或其他畸形文本
  按原文显示，绝不猜测。超出 JavaScript 安全整数范围的编号同样按原文显示。
- **未知编号保持诚实。** 快照中没有的编号（含负数）显示为 `洛谷标签 #<id>（名称未收录）`，原始字符串仍在
  「查看原始标签编号」中原样可查；新编号在更新快照前一直如此，不会被套用相近名称。
- **一行一个平台身份，原始文本不丢失。**
  - 同一编号的不同写法（如 `luogu-tag:3` 与 `luogu-tag:03`）合并为一行，并保留全部原始字符串；
  - 编号与平台同时给出的**完全相同**名称合并为一行，同样保留两条原文；
  - 两个**不同**编号即使名称相同也各自成行，计数、通过率与样本永不合并；
  - 当两个编号同名时，同名的纯文本标签保持独立，不会被归属到其中任意一个编号（与输入顺序无关）。
- **四类信息始终可区分。** 平台原始标签（含其显示名）、AI 建议、人工决定与已复核标签互不替代；本快照只服务于
  第一类的显示。

## 出现位置

| 位置 | 显示方式 |
| --- | --- |
| 题目详情 →「标签与来源」 | 标签列表显示可读名称；「查看原始标签编号」列出每条原文，并在洛谷来源下给出带链接的字典出处 |
| 训练计划 → 候选题（需开启剧透） | 临时原始标签显示可读名称，展开后可查原文与字典出处 |
| 知识点与薄弱项 → 平台标签参考（未复核） | 每行显示可读名称，名称下方保留原始编号；行与计数保持原样 |
| 知识点与薄弱项 → 知识点掌握情况 → 来源标签对照 | 「原始标签」列显示可读名称并保留原始字符串；对照结果、未匹配判定与证据口径不变 |

## 测试与维护

- `tests/ui/raw-tag-view.test.ts` 固定了外部可观察的行为：已知编号（3 动态规划 DP、7 贪心、53 树状数组）、
  只有编号的旧记录、未知/负数/畸形/超范围编号、非洛谷/手工/缺失/镜像/错误主机隔离、空与缺失输入、
  编号与同名文本的两种输入顺序、同名不同编号的身份保留、来源与账号切换，以及输入不可变。
- 更新快照：重新核对官方公开数据后替换 `src/ui/luogu-tag-dictionary.ts` 中的配对表，并同步更新条目数与
  核对日期；测试会固定条目总数与已知编号。用户侧无需任何迁移动作。
