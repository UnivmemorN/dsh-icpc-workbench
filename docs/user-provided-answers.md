# 用户提供解析

在「题库 → 题目详情」展开 **粘贴外部答案 / 用户提供解析**。填写来源标注（例如 GPT6、教师解析、自己整理），粘贴解题说明或代码；出处链接可以留空。点击 **保存为本地用户提供解析** 后，可点击 **选中此题并前往标签审核**，免费准备本题的分析，再显式启动模型调用。

保存只写本地，不调用模型，也不直接采用标签。之后显式启动分析、独立复核或提示时，DeepSeek V4.1 Flash 会收到原文及来源说明，仍按题解证据规则处理。独立复核也会检查遗漏。AI 训练计划只接收做题聚合和候选题元数据，不接收完整解析。

正文按原样保存，支持纯文本、Markdown 和代码，以安全文本显示；来源标注最长 200 字符，正文最长 200,000 字符。链接仅作引用，不会抓取；不提供链接时，保存的关联链接指向原题，页面明确区别于答案出处。用户标注的模型/作者名称不代表插件已认证来源或证明答案正确。

平台题解、用户提供解析、原始标签和人工决定分别保留。相同标注、正文及链接的重复粘贴复用快照；不同内容产生新快照并保留旧材料和分析。旧页面保存时如果题目材料已变化，会提示刷新，输入不会因失败清空。切换题目会清除该表单的临时草稿，避免保存到另一题。保存期间输入暂时锁定。

API 是现有 material.supplement 的可选 answer 字段：{sourceLabel, text, url?}。可与 statement 一同补充，不能与 editorial 同时提交。响应只返回快照和数量，不回显正文；未揭示题解的详情响应也不带正文或来源备注。没有新的数据库 schema 或外部模型接入：所有模型任务仍走 dsh 自身的审计接口，见 [统一模型策略](flash-only-policy.md)。
