# 个人水平校准与练习统计

> **开发参考** · [开发文档索引](development/README.md) · 日常操作请看[用户手册](user/README.md)。本文保留既有地址，供实现与排错核对。


从 0.1.10 开始，不再把通过题目的难度中位数当作选手实力。练习选题具有偏差，大量基础题会拉低中位数；它也缺少比赛时间限制和独立完成证据，因此中位数、四分位数以及最高 AC 难度都不能直接推导当前比赛水平。

在“薄弱项 → 能力评估 → 个人水平校准”填写 CF 水平下限、上限，然后保存。范围标明“用户自评”，按当前 CF 账号持久保存，导入不会覆盖。没有校准时显示“个人水平待校准”；清除自评同样记录新版本，不抹去历史。其他平台继续展示原生难度，不直接换算成 CF。从 0.1.11 可同步官方比赛评分，清除自评后可使用官方当前 rating；详见 [评分规则](ability-scoring.md)。未同步时不会自动访问平台，当前没有经过验证的自由练习转 rating 模型。

全部、近期、较早通过记录仍分别计算，各期中位数明确标为练习分布。个人校准不改写这些数据，也不把无复盘的 AC 变成独立完成。

新 AI 计划接收去除账号和时间标识的 trainingReference（范围、self_report/uncalibrated、版本）与所有时期的练习统计。自评范围是主要选题参考，模型只能从真实候选题中安排训练；候选不足时不能编造。无校准时按历史记录安排跨难度诊断。新输入的旧 baselineTrainingLevel/baselinePool/stretchPool 均为空，避免继续用中位数约束选题。旧不可变准备保持原样，生成前按当前数据重新准备；修改或清除自评会使旧准备失效。

存储升级为 schema v5，自动备份后仅增加 ability_calibrations 表。保存使用版本检查以拒绝过时修改，全部历史校准记录只追加。接口 ability.calibrate 仅接收 accountId、expectedRevision、range，来源与保存时间由服务填写。

本次修正是本项目对统计口径的调整，未移植第三方评级公式。题库、知识点和原型思路引用继续见 THIRD_PARTY_NOTICES.md。

0.1.11 补充：有官方分时，trainingReference 可为 official_rating；计划另含来源清晰的 competition 聚合。官方数据与用户自评分表保存，导入和评分同步都不覆盖自评。
