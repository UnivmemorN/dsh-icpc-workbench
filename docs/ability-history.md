# 历史记录与近期练习分布

> **开发参考** · [开发文档索引](development/README.md) · 日常操作请看[用户手册](user/README.md)。本文保留既有地址，供实现与排错核对。


0.1.10 修正：以下各期数值均为描述性练习分布，不是选手实力。个人水平使用[个人校准](ability-calibration.md)，不再用中位数生成水平范围。

入口：薄弱项 → 能力评估。默认并列显示三份评估，全部做题记录放在首位。

| 范围 | 使用的记录 |
| --- | --- |
| 全部做题记录 | 所有已导入、时间不晚于评估时刻的通过记录 |
| 最近 90 天新通过 | 首次已知 AC 落在最近窗口内的题目 |
| 90 天以前通过 | 首次已知 AC 早于最近窗口的题目 |

时间窗口取配置值。旧题重复 AC 不会刷新首次通过时间；同一题只算一次。近期记录充足时，另两份评估仍然始终计算，不再只是兜底。记录尚未导入或缺少题目难度时，系统无法自动补出这些证据。

各期先排除最新复盘中已知使用提示或参考题解的题目，再排除其余缺失或无效难度。其余所有题目参与该期估计，无复盘的 AC 保持“是否独立未知”。每期显示通过数、有效样本、有效独立记录、排除数及缺失数，三类数相加等于通过数。

Codeforces 至少 5 道有效题才给出该期的难度中位数（取整到 100）和样本 P25–P75 范围。低于阈值或近期没有通过记录时显示不足/无记录，不借用别期分数。CF 仅接受正整数 rating；洛谷等级 0 不作有效难度，其他平台只呈现原生维度分布，不换算成 CF。原生分布保留平台报告的原始数值，和排除非独立题后的估计样本口径不同。

全部记录与更早记录反映历史积累，不是对当前比赛 rating 的认证；近期中位数降低也可能只是选择了更容易的题，不能直接认定退步。近期练习样本统计单独折叠显示，保留原先的样本筛选口径；它不再生成或限制个人水平参考。

新 AI 训练计划接收同一份去除账号与题目标识的 history 聚合，并要求同时考虑历史积累和近期记录。新提示词版本为 planning-v3-calibration。摘要不包含账号、提交明细、复盘笔记或时刻字段；单纯时钟向前移动不会让准备失效，实际记录变化或题目跨出时间窗口则会使证据更新。

旧版不可变计划与请求可以原样读取；缺少 history 的旧准备不会被改写，重新生成前需免费重新准备。0.1.10 为个人校准增加 schema v5 表并自动备份；本页统计无自动导入或 AI 调用。
